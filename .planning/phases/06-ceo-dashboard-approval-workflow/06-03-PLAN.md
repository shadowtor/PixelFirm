    - A temp repo with one committed file then an uncommitted 3-line change: readDiff returns files [{ path, added: 3, removed: 0 }], unified containing "+" lines for them, truncated false, totalAdded 3.
    - A 600-line change: truncated true, unified has at most 400 lines and at most 65536 bytes, totalAdded 600.
    - A repo whose branch tracks an upstream with one unpushed commit plus an uncommitted change: the diff includes both (base = merge-base with @{upstream}); a repo with no upstream diffs against HEAD.
    - Fail-first control: with `git config diff.external` and a textconv driver set to commands that write a marker file, running git's diff subcommand without the safety flags (the control) creates the marker in the uncommitted working tree; after deleting it, readDiff leaves no marker.
    - A binary file change reports added 0 and removed 0 (numstat "-").
  </behavior>

  <action>
RED first. Create diff.ts with `export interface DiffSummary { files: { path: string; added: number; removed: number }[]; unified: string; truncated: boolean; totalAdded: number; totalRemoved: number }` and `export async function readDiff(worktreePath: string, caps = { maxLines: 400, maxBytes: 65_536, maxFiles: 500 }): Promise<DiffSummary>`. Every git call uses execa with array args and cwd worktreePath and starts from a constant BASE_ARGS = ["--no-ext-diff", "--no-textconv", "--no-color"] (Pitfall 10). Base: try `git rev-parse --abbrev-ref --symbolic-full-name @{upstream}`; on success base = stdout of `git merge-base HEAD @{upstream}`, otherwise "HEAD". Run `git diff <BASE_ARGS> --numstat <base>` for files and totals (a "-" count is 0; totals sum every file even past maxFiles, which only caps the files array), and `git diff <BASE_ARGS> <base>` with maxBuffer 8 MiB for the unified text; cut at maxLines lines then at maxBytes bytes (never mid-UTF-8 sequence: cut on a line boundary), truncated = anything cut. Untracked files are not in git diff; say so in the doc comment. Only read-only subcommands appear in the file, so no-mutating-git.test.ts stays green. Export readDiff and DiffSummary from index.ts.
