<objective>
Make the worker actually run the gated agent, and make the round-trip survive the worker restarting.

Today apps/worker only runs read-only poll adapters, and ClaudeCodeRuntime was only ever driven by
a demo script. This plan hosts the runtime in the worker with the 06-01 broker as its decision source,
adds the hello/bootId handshake, and implements D-02 on the control plane: a restarted worker's open
requests expire (never approve) and their tasks go blocked, so the agent leaves the CEO room; the CEO
can then resume the task from History.

Output: worker composition + env-launched task, reconcile on hello, the resume route and the worker's
validated resume handler.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| control plane -> worker (task.resume) | the path in the message is untrusted until checked against the worker's own repo |
| worker env -> running agent | the task prompt is the local operator's, never the network's |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-04-01 | Elevation | remote task start (SEC-03) | high | mitigate | tasks start from worker env only; downlink closed to decision and task.resume; no prompt field |
| T-06-04-02 | Tampering | task.resume worktreePath | high | mitigate | handleResume accepts only paths returned by listWorktrees(repoPath); test with a foreign path |
| T-06-04-03 | Elevation | restart during a parked call | high | mitigate | reconcile records expiry + blocked; never approves; D-02 |
| T-06-04-04 | Tampering | duplicate hello / redelivery | medium | mitigate | unique index makes expiry idempotent; broker single-resolve makes redelivery idempotent |
| T-06-04-05 | Spoofing | hello from another worker | medium | mitigate | reconcile keys on the authenticated workerId only |
| T-06-04-06 | Tampering | resume CSRF | high | mitigate | requireCsrf + requireCeo on the resume route |
</threat_model>
