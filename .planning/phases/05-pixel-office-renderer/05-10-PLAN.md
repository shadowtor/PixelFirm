<objective>
Close CR-02 (the 05-08 regression that paints a row-2 agent's blocked glyph entirely inside the row-1 agent's sprite), WR-08 (every agent renders byte-identical pixels), IN-06 (the z-sort comment states the opposite of the code) and IN-04 (unvalidated fixed-index frame access).

**The geometry, worked out — this is why a gutter row alone is not enough.** The MetroCity frames are 16 wide x 32 tall (pinned by `spriteData.test.ts`), the grid pitch is `TILE_SIZE = 16`, the glyphs are 11 x 13, and `BUBBLE_ICON_GAP_PX = 2`. With `offsetY = 0` (the map exactly fills the canvas), a character on interior row `r` has `drawY = 16r - 24` and an above-the-head glyph at `[16r - 39, 16r - 26]`. That is only on-canvas from `r >= 3`, and it only clears the sprite box of the desk row behind it (`[16(r-p) - 24, 16(r-p) + 8]`) when the row pitch `p` satisfies `16p > 47`, i.e. `p >= 3`. 05-VERIFICATION.md's suggested single top gutter row moves the first desk to row 2, where `16r - 39 = -7` is still negative — the clamp would still fire and the defect would survive. The correct layout is **first desk row 3, pitch 3** (desk rows 3, 6, 9 -> 54 desks on the default 20x11 grid), which makes the clamp unreachable in the default office, and a renderer fallback that attaches the glyph to its OWNER's sprite box rather than to the canvas for any layout that does not give headroom.

Purpose: make criterion 2 ("a blocked or waiting agent is visually distinguishable at a glance from an active agent") true for the right agent, and make desks tellable apart at all.
Output: an owner-bound glyph placement rule, a desk layout with real headroom, per-agent identity hue, and the two-character composite test that would have caught the regression.
</objective>
