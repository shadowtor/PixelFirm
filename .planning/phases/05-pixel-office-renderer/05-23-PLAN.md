<objective>
Close UAT gap G-05-2 (Medium): the waiting_for_ceo orange '?' goes muddy in grayscale and colour-deficiency views. Root cause (.planning/debug/ceo-glyph-contrast.md): `bubble-permission.json` has no dark enclosing outline; its only edge colour #8a5a00 (luma 94) sits midway between wall (60) and floor (128), and the stem base and dot — the features that make it a question mark — are drawn mostly in that edge colour, so they vanish. The hourglass has the same class of weakness (1 px mid-luma body, 1 px neck). `bubbleSprites.test.ts` checks mask uniqueness only, never contrast.

Fix: re-author both glyphs with a closed near-black outline and a fill that contrasts with it, draw the '?' stem/dot in the fill colour, widen the hourglass neck, and add the missing guard tests (derived from STATUS_MAP's frozen entries so a future frozen status is covered automatically). This implements D-03 (distinct glyph + frozen pose; colour never the only signal) and the G-05-2 missing items.

Output: two re-authored JSON glyphs, four new guard tests, UI-SPEC inventory + format-contract amendment.
</objective>
