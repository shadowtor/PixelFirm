<objective>
Close CR-01, the headline gap: `apps/web` has no live path that creates or updates a Character, so agent appearance is frozen at the connect-time snapshot fold until the user reloads the page. This also unblocks HANDOFF-01's `if (!fromChar || !toChar) return;` guard, which can never be satisfied in production today because nothing creates a Character from a live event.

**Deviation from the verifier's suggested fix — recorded deliberately, not a silent scope change.** 05-VERIFICATION.md's `missing:` list proposes "a `task.status_changed` branch in `deriveCharacterUpsertFromStatusEvent` reusing company-core's `deriveAgentStatus`, so the live path and the fold path cannot drift." That specific shape cannot deliver the stated property: `deriveAgentStatus({ taskStatus, gsdCategory })` needs `gsdCategory`, which lives in `ProjectionState.gsdObservations[companyId].category` (see `packages/company-core/src/reducer.ts`'s `task.status_changed` handler), not on the event. A stateless mapper has no access to it and would therefore resolve CODING where the fold path resolves RESEARCHING / PLANNING / TESTING / REVIEWING / DISCUSSING / DEPLOYING — drift on 6 of the 15 AgentStatus values, which is exactly what the requirement forbids. This plan instead runs the *same* `reduce()` the snapshot fold runs, holding a live `ProjectionState` in `apps/web` and upserting every agent whose projection entry changed. That is a strictly stronger form of the required property (the live path and the fold path are literally the same code), and it additionally makes `gsd.phase_observed`, `agent.handoff_requested` and `agent.handoff_completed` live-reactive for free.

Purpose: make criterion 1 ("agents visible with sprites/animations matching their real current state") true LIVE rather than only after F5, and make criterion 3's choreography reachable on the real producer path.
Output: a live projection applier in `apps/web`, wired into `App.tsx` with the ordering guarantee the handoff FSM depends on, plus the first wired test that actually renders `App` (closing the OFFICE-02 test-tier prohibition).
</objective>
