<objective>
Close UAT gap G-05-P6 (polish item 6): the renderer must output only the office, with no black or unused area around it at the OBS source size.

Root cause (05-UAT.md): App.tsx subtracts a 24 px footer allowance before flooring the scale, so a 1280x720 source gets (720 - 24) / 176 = 3.95 -> scale 3. The canvas is 960x528, pinned top-left, and the rest of the viewport shows the black body (index.html `background:#000`). 1920x1080 only fits because scale 6 plus the footer happens to be exact.

Fix, which is also the planner's decision: size from the full viewport (1280x720 -> 4, 1920x1080 -> 6). Centre the canvas in a full-viewport wrapper painted WALL_COLOR, so any remainder matches the office border. Keep the attribution as the existing fixed DOM footer, now with a transparent background so it sits over the office's bottom wall row. The DOM footer is kept rather than drawing the text on the canvas because App.test.tsx pins the sentence in the rendered markup (SC4). Documented OBS sizes are exact multiples of 320x176.

Output: full-viewport sizing, WALL_COLOR surround, transparent footer overlay, App tests, live TRUTH 0 at two viewports with a no-black screenshot check, UI-SPEC sizing note.
</objective>
