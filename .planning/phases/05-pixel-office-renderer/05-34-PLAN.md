<objective>
Close UAT gap G-05-P2 (polish item 2): handoff participants must use fixed interaction offsets so that 2-3 agents never visually stack.

Root cause (05-UAT.md): `interactionTileFor` searches the receiver's seat row outward. Seats sit on odd columns 2 tiles apart, so the first free tile is always the even column between two seats. In row-b of the UAT, sender, receiver and a seated neighbour end up 16 px apart in a line, with 14-px-wide ink leaving 2 px between them.

Fix, which is also the planner's decision: fixed slots in layout data on the central aisle (row 6). It is the only interior row two tiles from every seat and standing spot, so the sender can never be shoulder-to-shoulder with anyone. Offsets are +1, -1, +3, -3 columns from the receiver's home, taken in that order and spaced so that no two senders or bystanders touch. For a row-4 receiver the sender stands across the desk. For a row-8 receiver it stands in the aisle behind. The sender faces the receiver on the dominant axis. This also makes 05-REVIEW WR-05 (a sender waiting on a vacant home) unreachable by construction, since no slot is a home. It supersedes 05-27's seat-row search at the user's request. 05-33 already made bubble placement independent of where senders stand.

Output: layout slots, the new slot choice and facing, rebased choreography tests, spacing and ink-separation sweeps, the live mirror, and the UI-SPEC layout note.
</objective>
