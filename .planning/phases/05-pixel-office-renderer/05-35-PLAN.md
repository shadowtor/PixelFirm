<objective>
Close UAT gap G-05-P4 (polish item 4): keep the 12-character task truncation in the bubble, but keep the full title available so it can be surfaced later by hover, click, dashboard or an expanded interaction.

Root cause (05-UAT.md): the full title is already stored (`registerTaskTitle` / `getTaskTitle`) and is only cut at template time. What is missing is a host-facing read path: nothing tells a host which task and agents an on-screen bubble belongs to, or where that bubble is.

Fix, which is also the planner's decision: one read-only accessor `getActiveHandoffs()` built from the handoff records and the title registry, plus the rect of the bubble the renderer actually drew last frame. Deliberately left out: any hover or click UI, any event subscription, any per-bubble id scheme. A host polls this once per interaction, which is enough for the hit-test the gap asks for.

Output: the accessor and its export, a real-flow test, and a UI-SPEC copy note.
</objective>
